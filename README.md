# Netflix Content Analysis (Power BI)

## 📊 Project Overview
This project consists of an interactive Power BI dashboard analyzing Netflix content data.  
The goal is to explore trends in content type, release year, country, genre, and ratings.

---

## 🛠️ Tools Used
- Power BI  
- CSV Dataset  
- Data Cleaning & Transformation  

---

## 📈 Key Features
- Interactive dashboard with filters (slicers)  
- KPI cards for quick insights  
- Trend analysis by release year  
- Top categories and content distribution  

---

## 🧠 Insights
- Identified content trends over time  
- Analyzed distribution by country and genre  
- Highlighted most common content types
